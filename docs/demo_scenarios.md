## Kịch bản 1- Thai phụ theo dõi thai kỳ

Patient đăng nhập
→ tạo hồ sơ thai kỳ
→ nhập ngày dự sinh
→ hệ thống tính tuần thai
→ hệ thống tạo timeline
→ patient xem mốc tiếp theo
→ patient hỏi AI
→ AI trả lời có nguồn

## Kịch bản 2-Phát hiện dấu hiệu nguy hiểm
Patient khai báo triệu chứng
→ rule engine kiểm tra
→ phát hiện red flag
→ hiển thị cảnh báo cố định
→ tạo clinician alert
→ doctor xem và xử lý cảnh báo

## Kịch bản 3 -Bác sĩ đổi ngày dự sinh
Doctor mở hồ sơ thai phụ
→ cập nhật ngày dự sinh
→ lưu lịch sử thay đổi
→ tính lại tuần thai
→ cập nhật milestone tương lai
→ patient xem timeline mới
